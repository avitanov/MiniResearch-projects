# Loka Mini Research Projects

**Internship context:** These studies were completed during the Loka Machine Learning Internship. References to "Week X", task numbers, and labs follow the original internship curriculum.

Focused studies completed by Atanas Vitanov during the Loka ML internship.
Each study has its own environment, notebook outputs, and README.

| Study | Question | Main contribution |
|---|---|---|
| [Financial Risk EDA](financial-risk-eda/README.md) | Is the supplied dataset suitable for risk modeling? | Missingness analysis, domain validation, and assessment of weak feature-target associations. |
| [Human Activity Recognition](human-activity-recognition/README.md) | How well do activity classifiers generalize across subjects? | SGD logistic regression from scratch, model comparisons, and subject-aware evaluation. |
| [GSM8K LoRA Study](gsm8k-lora-study/README.md) | Do adapter and formatting choices improve arithmetic reasoning? | Rank/alpha ablations, baseline comparisons, negative results, and evaluation limitations. |
| [NLP Embeddings, Classification, and Retrieval](nlp-embeddings-and-retrieval/README.md) | When does additional model complexity improve results? | NumPy Word2Vec, TF-IDF versus DistilBERT, keyword versus FAISS search, and a Streamlit results viewer. |

No trained weights or fitted model artifacts are included. Saved notebook outputs
record the original experiments; packaging these studies did not rerun them.
